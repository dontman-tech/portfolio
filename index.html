Applied AI / Voice Assistant · Flagship

ARIA — Voice AI Assistant

The problem: voice assistants stop working the moment the internet does — useless on a student budget in Cameroon. I built ARIA around a skill router that answers locally when offline and escalates to the cloud only when it must: an Android bridge server drives Wi-Fi, flashlight, alarms and screenshots natively, a PWA control panel stays usable on any device, and DeepSeek integration is a pluggable upgrade, not a dependency. Outcome: an assistant that keeps its core skills in airplane mode.

Mobile App / Marketplace

Re-kollect — Waste Collection Marketplace

The problem: in many Cameroonian neighbourhoods, waste collection is a cash and coordination mess — generators can't find collectors, collectors can't find work. I shipped the Flutter marketplace connecting the two sides: role-based auth, a Firestore request lifecycle, live map pinning via Nominatim geocoding, and FCM fan-out so a posted pickup reaches nearby collectors in seconds. Built as the capstone of a team hackathon cycle — my slice was the backend flows and geo layer.

Flutter Dart Firebase OSM

Computer Vision / Gesture Control

Air Canvas Gesture Drawing

A computer-vision take on "no mouse, no problem". MediaPipe hand landmarks drive a five-gesture mode machine — draw, hover, erase, palette, clear — where the hard part wasn't tracking, it was gesture stability: filtering pinch jitter so a trembling hand doesn't spray dots across the canvas. Tuning the temporal smoothing against real webcam footage at 15fps was the whole project.

Web Security / Utility

NESAC Password Strength Checker

Most strength checkers give a color bar and a shrug. NESAC scores password resilience and then explains the verdict in plain language — which pattern leaked it, why it falls, how long a brute-force would take — and generates secure passphrases on the spot.
