# TAMIF — Portfolio

Hey there 👋 I'm tamif and this is my portfolio website 
putting this out here so anyone can copy the template , edit it and create theirs..... Have fun 😊 

Zero-build: one `index.html` with vanilla ES6, Tailwind via CDN, Lucide via CDN, Kanit from
Google Fonts. No npm, no bundler, no Node step.

## Preview locally

```bash
python3 -m http.server 12000
```

Then open <http://localhost:12000>.
