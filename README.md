# TAMIF — Portfolio

Hey there 👋 I'm tamif and this is my portfolio website. Putting this out here so anyone can copy
the template, edit it, and create theirs — have fun 😊

Zero-build: one `index.html` with vanilla ES6, one `styles.css`, no npm, no bundler, no Node step.
Fonts come from Google Fonts; icons are inline SVG, so there are no other CDN dependencies.

## Preview locally

```bash
python3 -m http.server 12000
```

Then open <http://localhost:12000>.

## Editing it

- **Your photo** — replace `portrait.png` (a transparent PNG works best; it sits over the
  tangerine block).
- **Your résumé** — replace `resume.pdf`.
- **Colours and type** — everything is a token at the top of `styles.css`. Change `--tangerine`
  to re-skin the whole site.
- **Projects** — each project is a `.proj` article in `index.html`; the artwork is the inline
  `<svg>` inside it.

See `AGENTS.md` for how the design system is put together.
